VКак работаю с моделямиWorking with models

Правила, проверки и ограничения записываю в репозиторий и дублирую в CI, чтобы их нельзя было обойти. Rules, checks and constraints go into the repository and are duplicated in CI, so they cannot be bypassed.

Cursor и Claude Code. Код пишу узкими шагами, проверку отдаю отдельному агенту. Тесты, которые модель написала вместе с реализацией, доказательством не считаю. Без собственного ревью код не отдаю.

Cursor and Claude Code. I write code in narrow steps and hand review to a separate agent. Tests that a model wrote together with the implementation do not count as proof. Nothing leaves my hands without my own review.
